NAVSHIELD DEMO

NAV-Guard AI is an intelligent compliance monitoring and NAV prediction system designed to analyze mutual funds, detect liquidity risks, and simulate trade impact. This project provides a modern dashboard interface for financial analysis and compliance tracking.

PROJECT OVERVIEW

NAV-Guard AI helps in:

Predicting NAV impact based on trade size
Monitoring liquidity scores of funds
Detecting potential frontrunning risks
Visualizing financial data using interactive charts
Providing compliance insights for auditors and analysts

FEATURES

User authentication interface (Sign In / Register)
Interactive dashboard with multiple tabs
NAV prediction graph (Actual vs Predicted)
Portfolio visualization using pie chart
Market analytics with bar and line charts
Compliance risk categorization
Trade simulation for NAV impact
Frontrunning alert system
Chatbot interface for querying insights
CSV export functionality

HOW TO RUN THE PROJECT

1.Open terminal in project folder
2.Install dependencies
pip install -r requirements.txt
3.Run backend server
python app.py
4.Open the frontend
Double click home.html or open in browser
5.Use the application
Login with any username
Enter fund name
Analyze data

NOTE

The frontend connects to a local backend at:
http://127.0.0.1:5000
Make sure the backend is running before using features

LIMITATIONS

Works only on local system (backend not deployed)
Requires manual backend startup
No real-time market API integration
